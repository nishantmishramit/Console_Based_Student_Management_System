# Console-Based Student Management System (SMS) 🎓

A core Java application demonstrating fundamental Object-Oriented Programming (OOP) concepts and basic Data Structures (`HashMap`). Designed as a practical starter project for final-year CSE students.

---

## 📌 Concepts Covered

* **Object-Oriented Programming (OOP):**
  * **Classes & Objects:** Blueprints (`Student`, `Operations`) and instance creation.
  * **Constructors:** Parameterized constructor initialization in `Student`.
  * **Encapsulation & State:** Object attribute manipulation and state persistence.
  * **String Representation:** Overriding `toString()` for customized output formatting.
* **Data Structures & Collections:**
  * **`HashMap<Integer, Student>`:** Fast key-value lookup, insertion, and deletion using student roll numbers as primary keys.
* **Core Java Mechanics:**
  * Static vs Instance variables and methods.
  * Interactive console I/O processing using `Scanner`.
  * Control flow using `switch-case` constructs and `while` execution loops.

---

## 🚀 Key Features

* **Create Student:** Add a new student record (Roll Number, Name, Branch) into memory.
* **Update Student Details:** Selectively modify existing student fields by roll number.
* **Delete Student:** Remove a student record using their unique roll number.
* **Attendance Tracking:** Mark student presence (`isPresent` flag).
* **Display Records:** Output all stored student records using `HashMap.forEach()`.
